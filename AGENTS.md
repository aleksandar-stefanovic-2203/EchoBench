# EventBench project conventions

- The application name is **EventBench**. Use this capitalization in user-facing branding; use `eventbench` for package and technical identifiers.
- All application text must be in **English**, including screens, navigation, buttons, placeholders, accessibility labels, validation messages, API errors, demo content, and AI-generated summaries and recommendations.
- Keep the HTML document language and date presentation aligned with English.
- Write new project documentation in English. Historical documents in `plan-hakaton` describe the original prototype; this naming and language decision supersedes their references to Gemify or a Serbian interface.
- Preserve user-authored survey questions and responses as entered. AI narrative output must be English regardless of input language; source quotations must retain their original content.
- Keep existing tests aligned with English labels and EventBench branding.
